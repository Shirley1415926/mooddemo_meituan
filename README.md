# 慢慢 · 情绪日记与自我关怀

一个无需注册、可直接使用的中文情绪日记 Demo，适配手机和桌面。

## 本地预览

```bash
python3 -m http.server 4173 --directory public
```

打开 http://localhost:4173 。也可直接打开 `public/index.html`，建议使用 HTTP 预览以获得一致的浏览器存储和音频行为。

## 已实现

- 五档心情、多选影响因素、日记文字与浏览器本地持久化。
- 日记回顾、删除确认、带封面的 PDF 打印版、单篇高清 PNG 导出及 JSON 备份；示例数据与真实记录隔离。
- 7 / 30 天趋势、低落时的常见标签、基于记录的关怀建议。
- 一分钟动态呼吸练习、三分钟可调音量环境声音、两分钟分步舒展。
- 练习完成反馈、累计完成次数、移动端底部导航。

## 实现边界

纯 HTML / CSS / JavaScript，无构建依赖、外部字体、外部音频、API 密钥或收费服务。
分析采用透明的标签统计规则，没有接入大模型，不提供心理诊断。
环境音由 Web Audio 在设备上合成。
日记仅保存在当前浏览器 localStorage，不跨设备同步；清除站点数据会丢失记录。

## 匿名心情广场（演示版）

- 示例故事、情绪与话题分类、三种支持性回应。
- 日记保存后自愿分享，也可在广场独立发帖；发布前可修改内容、确认隐私、设置折叠提醒。
- 发帖默认待审核，通过明确标注的按钮模拟审核后展示；支持撤回自己的分享。
- 举报原因记录、隐藏与恢复、社区约定与放松练习入口。
- 所有帖子和交互仅存在本浏览器，不构成多人社群；没有真实审核服务。
- 手机采用五项底部导航、单列信息流、横向话题筛选、底部表单、44px 主要触控目标及安全区域适配。桌面采用侧栏和双栏信息布局。

验证：360px / 390px 手机与 1440px 桌面布局；本机发帖、模拟审核、刷新保留、回应切换、举报隐藏。

## 陪伴与主动关怀（产品框架）

- 五档心情与精力分开记录，支持具体感受、编辑与原日期保留；旧数据不会被重写。
- 宠物树洞使用明确标注的本地分支对话，支持倾听/行动模式、话题连续性和回访情境。没有真实大模型。
- 陪伴偏好只在用户明确开启后保留昵称和方式，可查看和关闭；不自动记忆日记或聊天。
- 轻关怀计划根据时间和偏好生成 1–3 个可选行动，可缩短、替换或跳过，不设连续打卡。
- 练习完成/提前结束均可反馈。只有完整计时结束才增加完成次数，提前结束不会算完成；计划通过稳定 ID 关联反馈。
- 日历仅演示忙闲范围授权、繁忙/轻松情境、空隙建议及关闭提醒。
- 手表仅演示心率/睡眠范围选择、示例信号与主动心情确认。身体信号不是情绪诊断，不连接真实设备。
- 导出支持近 7 天、近 30 天或全部记录。

演示路径：记录 → 保存后选择伙伴或计划 → 选择时间/方式 → 练习 → 自愿反馈。
手机与桌面使用同一份静态文件；主导航保持五项，陪伴功能通过页内四个入口展开。

更新部署时上传整个 public 目录，尤其不要遗漏 companion.js 和 journey.js。本次仍无需环境变量、安装或构建命令。

验证：JavaScript 语法、git diff 检查；tests/support.test.cjs 验证提前结束不算完成、重复完成不会计数、旧练习不会误完成替换后的计划；浏览器验证编辑持久化、连接范围、日历声音时长、记忆开启、分支对话、反馈及 360/390/1440px 布局。

### 陪伴小屋与界面层级

- 新增 SVG 小猫/小狗场景：呼吸、眨眼、摇尾巴；摸头、零食、追球和静伴有对应动画与文字反馈，可暂停动画，支持系统减少动态效果设置。
- 自愿互动与聊天留下本机回忆，不保存聊天内容。同日同类型仅记录一次；在 3/7 个不同日期互动后进入新阶段，不要求连续，不扣除成长；可预览体型和小屋装饰变化，也可清除回忆。
- 宠物场景为陪伴页视觉主体；聊天随后，轻关怀建议、练习、设备连接为后续入口。记录、趋势、社群、陪伴分别使用橄榄绿、蓝、紫、暖杏色强调。
- 仍是静态产品原型：真实 AI、真实设备接入、跨设备同步均未启用。部署时上传整个 `public/` 到原 CloudBase 应用，保持域名不变。
