# 慢慢 · 情绪日记与自我关怀

一个无需注册、可直接使用的中文情绪日记 Demo，适配手机和桌面。

## 本地预览

```bash
python3 -m http.server 4173 --directory public
```

打开 http://localhost:4173 。也可直接打开 `public/index.html`，建议使用 HTTP 预览以获得一致的浏览器存储和音频行为。

## 已实现

- 五档心情、多选影响因素、日记文字与浏览器本地持久化。
- 日记回顾、删除确认、带封面的 PDF 打印版、单篇高清 PNG 导出及 JSON 备份；示例数据与真实记录隔离。
- 7 / 30 天趋势、低落时的常见标签、基于记录的关怀建议。
- 一分钟动态呼吸练习、三分钟可调音量环境声音、两分钟分步舒展。
- 练习完成反馈、累计完成次数、移动端底部导航。

## 实现边界

纯 HTML / CSS / JavaScript，无构建依赖、外部字体、外部音频、API 密钥或收费服务。
分析采用透明的标签统计规则，没有接入大模型，不提供心理诊断。
环境音由 Web Audio 在设备上合成。
日记仅保存在当前浏览器 localStorage，不跨设备同步；清除站点数据会丢失记录。

## 陪伴与主动关怀（产品框架）

- 五档心情与精力分开记录，支持具体感受、编辑与原日期保留；旧数据不会被重写。
- 宠物树洞使用明确标注的本地分支对话，支持倾听/行动模式、话题连续性和回访情境。没有真实大模型。
- 陪伴偏好只在用户明确开启后保留昵称和方式，可查看和关闭；不自动记忆日记或聊天。
- 轻关怀计划根据时间和偏好生成 1–3 个可选行动，可缩短、替换或跳过，不设连续打卡。
- 练习完成/提前结束均可反馈。只有完整计时结束才增加完成次数，提前结束不会算完成；计划通过稳定 ID 关联反馈。
- 日历仅演示忙闲范围授权、繁忙/轻松情境、空隙建议及关闭提醒。
- 手表仅演示心率/睡眠范围选择、示例信号与主动心情确认。身体信号不是情绪诊断，不连接真实设备。
- 导出支持近 7 天、近 30 天或全部记录。

演示路径：记录 → 保存后选择伙伴或计划 → 选择时间/方式 → 练习 → 自愿反馈。
手机与桌面使用同一份静态文件；主导航保持五项，陪伴功能通过页内四个入口展开。

更新部署时上传整个 public 目录，尤其不要遗漏 companion.js 和 journey.js。本次仍无需环境变量、安装或构建命令。

验证：JavaScript 语法、git diff 检查；tests/support.test.cjs 验证提前结束不算完成、重复完成不会计数、旧练习不会误完成替换后的计划；浏览器验证编辑持久化、连接范围、日历声音时长、记忆开启、分支对话、反馈及 360/390/1440px 布局。

### 情绪梳理与自助调节

首页直接展示近 7 天低落记录中共同出现的影响因素，并提供进入分析和自我梳理的入口。分析页直接呈现标签统计及对应的小行动；图表可按需展开。

自我梳理分三步：具体情境 → 感受与在意的点 → 此刻需要的支持。用户可返回修改、重新开始，并可选择小猫陪伴、呼吸练习或轻关怀计划。梳理内容仅在本次页面会话保留，不自动写入日记。统计只表示共同出现，不声称推断情绪原因或提供心理诊断。页面仍为本地规则演示，未接入真实大模型；以后若接入，需要服务端、明确的数据授权、风险识别与人工支持入口。部署时须包含新增的 `public/reflection.js`。

小猫是产品的情绪聊天入口：未认养时首页与陪伴页明确引导先认养，认养后直接进入聊天；已认养时可从首页、小猫悬浮窗、陪伴小屋和保存日记后的提示进入对话。页面明确写出“先听用户说，再一起梳理感受”的用途，并持续标明当前回复为本地模拟、尚未接入真实 AI。

放松练习增加“按此刻困扰选择”的入口：学业/工作压力、思绪太满、久坐想活动、委屈想被理解。用户可更换选项；最近一条低落记录中主动标记的工作/学业/关系因素，只用于默认展开一个方向，不做自动诊断。建议分别引向呼吸、环境音、轻舒展或情绪梳理，并在卡片中写明研究来源和适用范围。研究启发的是练习类型，具体困扰与练习的匹配、1–3 分钟演示时长都未经验证，不承诺疗效。参考：[Balban 等（呼吸）](https://pubmed.ncbi.nlm.nih.gov/36630953/)、[Adiasto 等（音乐与压力恢复，整体结果不显著）](https://pubmed.ncbi.nlm.nih.gov/35714120/)、[Weinstein 等（单次运动）](https://pubmed.ncbi.nlm.nih.gov/38787545/)、[Affect labeling 实验（效果因情境而异）](https://pubmed.ncbi.nlm.nih.gov/36580454/)。部署时包含新增的 `public/tailored-care.js`。

### 自主认养与卡通形象

未认养时不默认生成宠物。流程：选择暖橘白/银灰白外貌 → 起名（1–12 字）→ 确认接回家。外貌、名字、认养日期保存在 `manman.adoption.v1`；认养卡可修改名字，保留认养时间与原有回忆。可以跳过认养使用日记、分析和放松功能。对话仍为分支演示。

形象按用户反馈更新为大眼睛、圆脸、短爪的 2D 卡通风格，替代写实小眼睛版本。使用内置 image_gen 生成，资源：`public/assets/xiaoman-room.jpg`、`public/assets/silver-room.jpg`。最终橘猫提示词：cute 2D kawaii orange-and-white chibi kitten, huge round expressive dark brown eyes with white catchlights, oversized round head, tiny pink nose, smiling mouth, short paws, plump body, smooth brown outlines and flat pastel colors; centered on sage cushion in simple cream room with arched window, plant, toy ball and bowl; no text or watermark. 银灰款编辑提示词：preserve the exact composition, huge sparkling eyes, proportions, pose, outlines and background; change only orange fur and stripes to silver/medium gray, keeping white muzzle/chest/paws and pink nose/ears.

### 猫咪短互动动画

互动区使用两套 4×2 透明角色动作图（`assets/apricot-actions.png`、`assets/silver-actions.png`），由内置 image_gen 生成：同一大眼睛卡通猫，依次为待机、左右蹭头、低头吃/舔嘴、抬爪/推球、蜷睡；银灰版仅替换毛色，保留全部姿势和位置。点击播放 4 帧、每帧 500ms，共约 2 秒后恢复待机；重复点击取消前一个动作，离开页面清理计时器。无暂停按钮，无循环待机动画；减少动态效果时仅展示对应静态姿势后恢复。

### 悬浮陪伴与交互动效

- 已认养的猫咪在各页面边缘陪伴，可点击展开摸头/回小屋菜单，可收起为侧边入口，设置仅本机保存。手机避开底部导航；输入和弹窗期间隐藏，减少遮挡。
- 每 22–40 秒可能做一次约 1.2 秒的小动作，不记录成长、不发提醒；页面隐藏、主动收起或系统减少动态效果时不主动播放。
- 小屋使用独立背景与角色层，可直接点击猫咪摸头。新增 `assets/room-background.jpg` 由内置 image_gen 编辑原卡通图，提示为：remove only the cat and reconstruct the empty sage cushion; preserve room, window, plant, bowl, ball, palette and composition; no animals or text.
- 页面切换 230ms，桌面弹窗进入 260ms、退出 160ms，手机底部弹层进入 280ms；重开弹窗会取消尚未结束的关闭操作。尊重系统减少动态效果设置。
- 参考：Finch 官方产品 https://finchcare.com/ （角色作为陪伴入口）；Material Duration & easing https://m1.material.io/motion/duration-easing.html （短过渡、自然减速和进入/退出时长差异）。未复用其他产品的角色或素材。

### 首次使用引导

首次访问自动启动六步导览：心情选择 → 日记 → 情绪线索与三步梳理 → 按困扰选练习 → 小猫情绪陪伴 → 心情广场。导览高亮真实入口，进入练习页时自动切换标签；已认养和未认养的小猫都指向正确按钮。支持下一步、上一步、跳过与 Escape。完成后进入记录页；跳过返回原页面，不创建记录、发帖或自动认养。更新后的引导使用 `manman.tour.v2`，因此旧版已完成引导的浏览器也会看到一次新版；顶部「使用指南」可随时重播。当前实际启用的是 `walkthrough.js`；早期 `onboarding.js` 概览保留作为历史资源，不会自动启动。部署时上传完整 `public/`。

### 情绪触发分析

「看见自己」默认显示触发因素分析：按低落记录次数排列用户标记的情境，点选后查看对应日记（每页两条），再将选中经历带入三步自我梳理。趋势图与统计保留在独立视图。示例分析与个人记录隔离，不会写入日记；共同出现不等于因果关系。分析入口、首页与新用户引导已同步。

### 记录、梳理与关怀（最新流程）

首页选择心情后即可顺手标记影响因素，不填也能保存。保存成功后优先引导梳理刚才的记录；原有聊天、计划、练习、分享入口在「其他关怀方式」中。梳理结果可编辑，并由用户点击后存回原日记，刷新后仍可回看、编辑和随 PDF 导出；示例梳理不会写入真实日记。根据用户选择的支持方式展示一条可跳过的建议，并说明它来自刚才的选择。手机端示例随梳理步骤展示，新用户导览加入影响因素这一步。
